1. Diseño y Maquetado de Interfaz Principal (index.html)

Hora / Timestamp: 2026-08-28 13:30

Objeto Técnico: Diseñar y maquetar la interfaz principal (index.html) en HTML5 aplicando etiquetas semánticas (<header>, <main>, <nav>, <section>, <article>, <footer>), corregir la jerarquía de encabezados (<h1> a <h4>), estandarizar las rutas relativas de navegación web y configurar la adaptabilidad responsive (meta viewport), registrando los cambios en Git mediante Conventional Commits[cite: 3].

Evidencia: HTML en github.png[cite: 3]

Impedimentos / Blockers: Los impedimentos presentados fueron el uso de la etiqueta no estándar <h7>, rutas con barras invertidas (\) que rompían la navegación web y la falta de las etiquetas <nav> y <meta viewport> para la semántica y adaptabilidad móvil[cite: 3].

Plan de Acción: Reestructurar la jerarquía de encabezados usando etiquetas válidas (<h4>), estandarizar todas las rutas de enlace con barras diagonales (/), envolver el menú dentro de la etiqueta semántica <nav> e incluir la configuración <meta viewport> en el <head> para garantizar la adaptabilidad responsiva y el cumplimiento de los estándares W3C[cite: 3].
